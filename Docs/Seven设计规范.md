# Seven 设计规范

## 信息层次与度量

原文、译文和当前任务结果占主要视觉层级。耗时、字数和工具操作使用次要文字色。强调色用于选中、焦点、启用和成功状态。错误使用错误色，警告使用警告色；未配置和禁用使用次要或禁用色。

[DesignSystem](../Sources/Seven/DesignSystem.swift) 定义排版、间距、圆角、图标与动效档位。按用途选取具名值：文字取 Design.Text，节奏间距取 Design.Space，与原生列表及表单边缘对齐取 Design.Layout 或 Design.Settings。SwiftUI 的零间距可直接写 0。确需新增档位时在定义处注明用途。原生表单行、开关及菜单保留系统度量。

## 主题与系统材质

- [ThemeManager](../Sources/Seven/ThemeManager.swift) 分别管理浅色与深色主题，系统默认主题跟随 macOS 的语义色和强调色。SwiftUI 根视图注入主题，AppKit 视图响应主题刷新；写入 CALayer 的颜色按当前有效外观解析并在外观切换时更新。
- 内容表面、浮窗、工具条、文本、分隔线及焦点色取自 [ThemePalette](../Sources/Seven/ThemePalette.swift)。设置与历史侧栏、权限引导沿用系统材质。服务品牌色、截图遮罩、像素网格、标注输出和 JPEG 白底保留各自的识别或像素含义。
- 设置侧栏使用单色图标。系统默认主题由 macOS 提供选中态，自定义主题沿用主题文字色和侧栏选中底色。
- 设置表单与标准行复用 [SettingsComponents](../Sources/Seven/SettingsComponents.swift)，选择控件优先使用共用的原生菜单或紧凑分段。图标按钮复用现有组件，符号变更与无障碍名称同步。
- 截图工具条的滑杆轨道使用主题色，滑块沿用当前系统外观。共用分段控件通过底色区分选中项。

## 反馈与无障碍

- 在发起操作处显示进行中、成功或可恢复的失败。成功用就地对勾或状态文字；需要处理的权限错误提供恢复入口。等待期间保留正在操作的上下文。
- 图标操作同时提供可理解的工具提示和无障碍名称，名称随动作切换；用文字或图形辅助表达选中、错误和禁用。键盘操作尊重当前焦点和输入法组合状态。
- 设置与翻译浮窗的编辑输入通过输入光标显示编辑位置。设置中的文本输入、搜索和提示词编辑器保留 Tab 导航。原生设置输入框的占位文字使用控件字体，随主题切换颜色。
- AI 自定义结果的 Markdown 排版沿用翻译浮窗的主题色、正文字号和统一滚动容器。以原生文本保留键盘选区与可访问性。内容重排时保持当前阅读行，用户启用流式跟随时才滚动到底部。
- Markdown 代码块使用统一背景及水平内边距，块头以注记字号显示语言，复制按钮使用浮窗同款图标和对勾反馈。语法着色沿用当前色板。引用竖线随层级缩进，分隔线延伸至正文右侧。表格按内容分配列宽，宽表滚动区域限定在表格内。
- 翻译浮窗外层滚动指示器仅显示原生滑块。悬停和拖动沿用原生滑块交互，轨道背景保持透明。
- 动效只表达操作响应或状态变化。开启“减弱动态效果”时直接呈现最终状态。切换主题和明暗外观时保留编辑、选择与滚动位置。

共用组件改动检查浅色、深色、系统默认及自定义主题，并覆盖禁用、键盘焦点和减弱动态效果。
