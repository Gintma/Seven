# 设置与服务草稿

## 从哪里改

[OnboardingFlow](../../Sources/Seven/OnboardingFlow.swift) 判定首次启动状态，[OnboardingWindow](../../Sources/Seven/OnboardingWindow.swift) 装配引导窗口。[SettingsView](../../Sources/Seven/SettingsView.swift) 持有导航选择及页面状态，[SettingsServiceDraft](../../Sources/Seven/SettingsServiceDraft.swift) 持有服务草稿和保存基线，[SettingsServiceCloseGuard](../../Sources/Seven/SettingsServiceCloseGuard.swift) 将离开确认接入原生窗口关闭动作。

## 必须保住什么

- 首次普通启动显示引导，已有使用痕迹的安装静默完成。待打开的图片优先交给[图片入口](OCR与图片输入.md)，新安装可在以后的普通启动继续引导。点击“开始使用”完成引导并打开输入翻译；关闭窗口或 Esc 只完成引导。录屏授权重启可继续未完成的引导。柴犬在窗口活跃且鼠标静止时眨眼和歪头，确认授权后点头，启用登录启动后眨眼。
- 设置侧栏依次为翻译（翻译设置、翻译服务、语音合成、历史记录）、截图（截图设置、钉图、工具条）、OCR（OCR 设置）、通用（基础设置、关于、诊断）。诊断页是否列出按[根规则第 4 条](../../AGENTS.md)判定。
- 设置窗口共用透明标题栏，滚动内容保持在右侧详情区域内。
- 应用菜单「关于 Seven」打开设置的「关于」页，并遵循服务草稿离开确认。该页提供检查更新、版本发布记录和 GitHub 仓库入口，持久化自动更新和更新按钮偏好。发现可安装的更新且开启更新按钮时，菜单栏下拉菜单和设置侧栏显示安装入口。
- 翻译设置从快捷键开始，依次为自动目标语言、语言检测、截图翻译、常用语言和窗口。“打开窗口时清空上次内容”在窗口分组中。
- “历史记录”页可以关闭历史写入，或选择保留 100、300、500（默认）、1000 条及不限制。调小上限会立即裁剪历史记录，收藏夹独立保存且无上限。
- **服务保存**：编辑详情字段、API Key、提示词和模型目录仅更新内存草稿；回车或失焦结束编辑。验证使用当前草稿且不落盘。验证成功就地显示连接耗时，诊断日志记录毫秒耗时。只有显式保存才提交变更的凭据与配置，先处理可能失败的凭据写入。列表启用开关和排序即时生效，保存草稿时保留这些即时变更。
- 切服务、切页、添加服务、关闭窗口共用“保存／不保存／取消”。保存失败时留在原页并保留草稿；放弃时恢复基线；取消时继续编辑。凭据读取失败时保护原值。关闭窗口或切换上下文后，旧验证和模型列表结果不能更新新页面。
