# 长截图

## 从哪里改

[AppDelegate+ScreenshotEditorActions](../../Sources/Seven/AppDelegate+ScreenshotEditorActions.swift) 接管长图会话，[ScreenshotScrollWindowController](../../Sources/Seven/ScreenshotScrollWindowController.swift) 控制采样、预览和工具条。[ScreenshotScrollMatcher](../../Sources/Seven/ScreenshotScrollMatcher.swift) 调用[纯 C 配准内核](../../Sources/ScrollRegistrationCore)，[ScreenshotScrollReferences](../../Sources/Seven/ScreenshotScrollReferences.swift) 有界缓存视口参照。

## 必须保住什么

- 直接长截图和编辑器中的长截图共用采集入口，同一时间只持有一个会话。直接入口只接收屏幕矩形。采集期间用户可滚动原窗口，覆盖层穿透点击；采样取边框窗口下方的画面，排除采集界面本身。
- 向上或向下滚动都能累积像素。有效配准后才推进基准，失配时保留已有拼图。重置保留选区，以当前画面开始新拼接；停止或取消会撤销监控、定时器和未完成任务。
- 选择编辑后停留在当前屏幕的居中编辑层，缩小预览保留完整导出分辨率。复制、保存、OCR 或钉图使用拼接结果完成所选操作；共享与其他输出遵循[截图与钉图](截图与钉图.md)。采样异常的专项记录遵循[根规则第 4 条](../../AGENTS.md)。
