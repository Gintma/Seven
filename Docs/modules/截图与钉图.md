# 截图与钉图

## 从哪里改

[FrozenScreenshotCapture](../../Sources/Seven/FrozenScreenshotCapture.swift) 协调冻结取区与整窗捕获；[ScreenshotEditorDocument](../../Sources/Seven/ScreenshotEditorDocument.swift) 管理标注与撤销。[ScreenshotPinWindowController](../../Sources/Seven/ScreenshotPinWindowController.swift) 管理现有钉图，[ScreenshotClipboardPin](../../Sources/Seven/ScreenshotClipboardPin.swift) 处理剪贴板入口。共享生命周期在 [ScreenshotSharing](../../Sources/Seven/ScreenshotSharing.swift)，持久保存由 [ScreenshotSaving](../../Sources/Seven/ScreenshotSaving.swift) 负责。

## 必须保住什么

- **智能选区**：关闭后跳过窗口内部元素识别，仍可悬停和点选整窗、手动框选，以及按住 ⌘ 在同一屏点选多个窗口。开启时只查询角色、结构和几何；外部 AX 查询在后台进行，自身窗口在主 actor 遍历已布局的视图。过期的命中不能覆盖当前选区。
- 普通截图、截图翻译和 OCR 共用冻结会话，各用途保留自己的选区策略。选择层持续显示到交付编辑器，取消后拒收迟到的图像。截图不主动隐藏翻译浮窗。标注按原图坐标绘制，工具条与辅助线不进入导出；连续拖动参数作为一次撤销。
- 截图、长截图和屏幕 OCR 缺少屏幕录制权限时，选择“打开屏幕录制设置”进入授权引导，选择“取消”或按 Esc 关闭提示。截图翻译在翻译浮窗内提供权限恢复入口。
- 用户触发“从剪贴板钉图”才读取剪贴板，优先取图片，也支持将纯文字在内存中排版为钉图。钉图原位编辑使用已有底图，完成只更新当前钉图，取消恢复原内容。显示缩放、不透明度和钉图阴影不改变导出的原图。
- **系统共享**仅由用户发起。取消目的地菜单会清理临时 PNG，并保留编辑现场。选定目的地即完成普通截图、长图或钉图编辑，关闭编辑层；钉图编辑同时应用本次修改。此时保留临时 PNG 供系统服务读取，服务完成、取消或失败时才清理。直接分享已有钉图时保留钉图，临时降低相关窗口层级，服务结束恢复层级；期间关闭或隐藏的窗口保持原状态。
- 主动保存时按设置选择位置和 PNG/JPG。固定目录中遇到同名文件生成新名称；“每次询问”使用系统保存面板确认的位置和文件名。写入失败时提示检查写入权限和可用空间，并保留编辑现场。PNG 保留透明区域，JPG 合成白底。[长截图](长截图.md) 与[图片导入](OCR与图片输入.md) 复用编辑器输出。
