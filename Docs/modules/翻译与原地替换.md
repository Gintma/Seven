# 翻译与原地替换

## 从哪里改

- 浮窗入口在 [AppDelegate+Panel](../../Sources/Seven/AppDelegate+Panel.swift)，布局与输入在 [AppKitTranslationViewController](../../Sources/Seven/AppKitTranslationViewController.swift)。[TranslationModel+Requests](../../Sources/Seven/TranslationModel+Requests.swift) 管理请求和卡片结果，语言识别与路由由同类型的 Detection、Languages 扩展负责。
- [ServiceWire](../../Sources/Seven/ServiceWire.swift) 适配服务协议；[ServiceEndpointVerification](../../Sources/Seven/ServiceEndpointVerification.swift) 管理验证时的端点选择。服务编辑与验证的持久化边界见[设置与服务草稿](设置与服务草稿.md)。
- [InputReplacementCoordinator](../../Sources/Seven/InputReplacementCoordinator.swift) 拥有独立替换会话。[InputReplacement](../../Sources/Seven/InputReplacement.swift) 核对目标与选区，[InputReplacementAXReader](../../Sources/Seven/InputReplacementAXReader.swift) 处理标准范围及富文本标记。

## 必须保住什么

- 划词只读取并展示翻译。卡片按服务实例顺序显示，在线请求耗时记录在诊断日志。新的翻译或取消操作应隔离上一代的迟到结果。用户向前滚动阅读时暂停流式跟随，回到底部后恢复。
- 划词缺少辅助功能权限、截图翻译缺少屏幕录制权限时，直接显示对应的权限引导。读取、截取或识别失败时，浮窗显示简短原因。无可用服务时，提示条提供服务设置和重试操作。
- “打开窗口时清空上次内容”默认关闭。开启后，关闭或收起浮窗即清除输入、译文和错误提示，保留源语言与目标语言。浮窗隐藏时开启该选项，下次打开输入翻译也会清除上次内容。跨桌面重定位保留当前内容，划词、截图翻译和 OCR 发送入口直接呈现新文本。
- 自带密钥服务的验证和翻译共用流式传输。用 ServiceStreamLineDecoder 保留 SSE 事件间空行，处理 CR、LF、CRLF、多行 data 和跨分片 UTF-8。AsyncBytes.lines 会丢弃空行。正式请求沿用选定的服务协议；对外错误只显示可理解的类别。
- 自定义提示词仅展开一次。请求创建时快照源语言、目标语言与第一语言；用户原文中与占位符同名的内容保持原样。
- “翻译并替换”只启动一个服务。请求取自两次一致的原生复制；写回前验证原进程、编辑控件、原文和 UTF-16 选区，粘贴后核验结果。目标变化或复制不一致时中止，空白输入静默结束。替换状态由独立提示显示，保持外部编辑器焦点。
